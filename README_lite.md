# 週案アプリ Lite版

中学校・高校の先生のための **週案・時間割・授業時数集計アプリ**。
HTML 1枚をブラウザで開くだけで使えます。サーバー不要・ログイン不要・無料です。

データは **このブラウザのlocalStorage に保存** され、外部には一切送られません。
（バックアップは「設定」タブからJSONで手動書き出し／読み込みできます）

---

## 旧版（school-weekly-plan）を使っている方へ：3つのアップデート

Lite版は、旧版に以下の機能を追加した **無料アップデート版** です。

| | 旧版 | Lite版（NEW） |
|---|---|---|
| 曜日 | 月〜金（週5日） | **月〜土（週6日）** |
| クラス・教科 | 固定 | **担当クラス・担当教科を自由に追加可能** |
| 1日の枠 | 1〜6限のみ | 1〜6限＋**🍱 昼食・🌙 放課後** の記録枠 |
| メモ欄 | 週単位の1欄 | **日別7セル（月〜土）** |

土曜授業がある学校、給食・放課後の動きを記録したい先生、
日ごとに連絡事項を分けて書きたい先生にぴったりです。

## 使い方（3ステップ）

### 1. ダウンロード
`index.html` を任意のフォルダにダウンロードします。

### 2. ダブルクリックで開く
`index.html` をダブルクリック → ブラウザで開きます。
（Chrome / Edge / Safari / Firefox どれでも動きます）

### 3. 「設定」タブから初期設定
- 担当クラス・担当教科を選択（または自由入力で追加）
- 1学期・2学期・3学期の開始日／終了日を入力

これで準備完了。「📅 週案」タブから入力を始められます。

## 主な機能

### 週案タブ（📅）
- 月〜土・1限〜6限＋🍱昼食・🌙放課後・📝メモ の入力
- 各セルをクリック → モーダルで詳細入力（クラス／教科／単元／授業回数）
- 行事・日課欄あり
- 印刷ボタン（A4横向き推奨）

### 時間割タブ（🗓）
- 学期ごとのベース時間割（基本パターン）を入力
- 「週案へ一括登録」ボタンで、学期の全週に一気に反映
- 既存入力を保持する「空欄のみ」モードあり

### 単元マスタータブ（📖）
- 教科ごとに「第N時 → 単元名」のテーブルを登録
- 週案で教科＋授業回数を入れるだけで単元名が自動表示

### 年間行事・日課タブ（📋）
- 年度の行事をCSV取り込み or 手動登録
- 週案の該当日に自動で行事が表示される

### 集計タブ（📊）
- クラス別／教科別の年間授業時数を集計
- 学期ごと・合計が一目でわかる
- 昼食・放課後は授業時数に含めません

### 設定タブ（⚙️）
- 担当クラス・教科の設定／追加
- 学期日程の設定
- **バックアップの書き出し／読み込み**（JSONファイル）

## データの保存場所

このアプリは外部サーバーを使いません。データは **このブラウザの localStorage** に
保存されます。具体的なキー名：

- `weekPlanLiteSettings` ・ `weekPlanLiteAnnual` ・ `weekPlanLiteTimetable`
- `weekPlanLiteData` ・ `weekPlanLiteMaster`

旧バージョン（v1：`weekPlan*` / v2：`weekPlanV2*` / BYOC：`weekPlanBYOC*`）とは
**完全に別の領域** に保存されるので、同じブラウザで併用しても干渉しません。

### バックアップは必ず取ってください

localStorage は **同じブラウザでしか読めません**。
- 機種変更・ブラウザの再インストール → データ消失
- シークレットモード → 終了時に消える
- ブラウザの履歴削除（サイトデータ含む） → 消える

「設定タブ」の「⬇ 全データを書き出す」を **月1回程度** 押して、
JSONファイルを Google Drive や iCloud に保存してください。
復元は同じく「設定タブ」の「⬆ バックアップを読み込む」から。
旧バージョン（v1／v2／BYOC）のバックアップも自動でLite形式に変換して読み込めます。

## フル版（有料・近日リリース）について

Lite版では **意図的に削っている機能** があります：

- 📅 **Google カレンダー連携** — 週案ボタン1つで自動同期
- ☁️ **Google Drive 自動保存** — 複数端末で同じデータを共有

これらを含むフル版（BYOC版）は **noteで500円の有料記事として近日公開予定** です。
- カレンダー同期：週案を入れるだけで時間割がカレンダーに反映
- Drive 自動同期：自宅・職場・スマホで同じ週案が見られる
- OAuth Client ID 取得から本番運用までの全手順を丁寧に解説（10〜15分）

詳細はnoteで告知します。

## GitHub Pages で公開する場合（任意）

このアプリは単一HTMLなので、GitHub Pages で簡単にWeb公開できます。

### 手順（10分）

1. GitHub にログインして、新しいリポジトリ（例：`weekly-plan-lite`）を **Public** で作成
2. 作成した `index.html` をそのリポジトリにアップロード（ドラッグ＆ドロップでOK）
3. リポジトリの「Settings」→「Pages」を開く
4. 「Build and deployment」の「Source」を **「Deploy from a branch」** に設定
5. Branch を `main`／`/(root)` にして「Save」
6. 数分待つと `https://<your-account>.github.io/weekly-plan-lite/` でアクセス可能に

これでURLを知っている人なら誰でも使えるようになります。
データは **各自のブラウザの localStorage** に独立保存されるので、
他の人のデータが混ざることはありません。

## トラブルシューティング

### ファイルを開いてもタブが表示されない
- ブラウザのJavaScript設定が無効になっている可能性があります。Chrome / Edge / Safari の最新版でお試しください。
- 古い iPad（iOS 14以前）の Safari では React 18 が動かない場合があります。

### データが消えた
- 同じブラウザで開いていますか？（Chrome→Safariのように切り替えると見えなくなります）
- シークレットモードで開いていませんか？
- ブラウザの履歴削除をしませんでしたか？
- バックアップJSONを保存していれば「設定」→「⬆ バックアップを読み込む」から復元できます。

### 印刷したい
- 週案タブの「🖨 印刷」ボタンをクリック。A4横向き推奨。
- ヘッダー部分など画面表示用のUIは印刷時に自動で消えます。
